# INT-2026-0001
 
Observation: the specification uses "change" for four things: a commit,
what a commit does to a file, the files a commit leaves behind, and a verb.
Run against concrete commits, this leaves cases undecided, such as whether
a commit that only adds a new file satisfies the Intake rule, whether a
commit that touches no files can be valid, and whether a deletion counts.
 
Need: "commit" and "change" name different things, and the Intake rule is
the most restrictive one that still admits the next commit: one Intake per
commit, added and named by that commit, alongside at least one other file
added or modified.
