# PBI-00040: Name the site Breadcrumbs, with the description and audience of README and VISION

## Directive

Bring the site in line with the naming of 2026-10-10, which
`README.md` and `VISION.md` already carry: the product is
Breadcrumbs, one record is a breadcrumb, and Breadcrumbs adds
traceability to whichever spec-driven development method a repository
uses.

**Scope:**
- In `site/content/_index.md`: the hero `# Breadcrumbs {#top}` with
  the description README opens with; the page's front matter `title`
  and `description` to match; the GitHub mark's alt text; the product
  name in "The report", "Honest scope" and "Status"; and in "Who it's
  for", VISION's audience and README's paragraph on what Breadcrumbs
  adds to an SDD method.
- In `site/hugo.toml`: `title`, the comment at its top, and the
  documentation page's description.
- In `site/layouts/baseof.html`: the landing page's `<title>`,
  "Breadcrumbs: traceability for spec-driven development".
- In `specs/site/spec.md`: the claim on the hero, the hero's
  description under Architecture, the audience row of the sections
  table, and the product name in its text.
- Leave every section id, the menu and the record's name
  (`breadcrumb`, `.breadcrumbs`, `breadcrumb.rules`) as they are.
  The repository and its address keep `breadcrumb-sdd`.
