# PBI-00015: Print problems as records in bcr verify

## Directive

Make `bcr verify` add a `problem` record to standard output for each
problem it finds, after the copy of its input, as
`specs/verify/spec.md` describes, so the stages after it in the pipe
can see it (ADR-0021).

**Scope:**
- In `cmd/bcr`, after the input is copied, write one `problem` record
  for each problem, in the order of standard error, with the records
  package.
- When the last line of the input has no line ending and a record is
  added, write a `\n` before the first one.
- Keep the copy byte for byte, and write nothing to standard output
  when a line of the input is not a record.
- Do not check the `problem` records of the input: they are of a kind
  `bcr verify` does not know, and are copied.
- Leave standard error and the exit status as they are.
- Add a test for each Scenario of `specs/verify/spec.md` that has
  none, and tick its Definition of Done.
- Document the added records in `docs/bcr.md` under `### verify`, and
  generate `docs/bcr.1` again. Keep the line the spec claims.

## Refinement Protocol
If adding the records needs a rule the spec does not state, add the
rule to the spec in the same commit. If it needs a change to the copy,
to the fields of the record, to standard error, or to the exit status
the spec defines, stop and ask.
