# PBI-00011: Pass every record on from bcr verify

## Directive

Make `bcr verify` copy its standard input to standard output, byte for
byte, as `specs/verify/spec.md` describes, so the stages after it in
the pipe receive every record (ADR-0016).

**Scope:**
- In `cmd/bcr`, read the whole input before writing anything. When a
  line is not a record, write nothing to standard output and exit 2,
  as before.
- Otherwise copy the input to standard output unchanged, line endings
  and records of unknown kinds included, then print the problems to
  standard error as before.
- Exit 2 when standard output cannot be written.
- Leave `internal/records` and `internal/crumb` as they are: the copy
  is the command's job (ADR-0013).
- Update the tests of `specs/verify/spec.md`'s Scenarios: each one
  that printed nothing now checks the input comes out unchanged; add a
  test for each new Scenario.
- Document the copy in `docs/bcr.md` under `### verify`, and generate
  `docs/bcr.1` again.
- Leave `.github/workflows/check.yml` and AGENTS.md's Toolchain as
  they are: the records they now print are harmless, and the pipe's
  next stage changes that line.
