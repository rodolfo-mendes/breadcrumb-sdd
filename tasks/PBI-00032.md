# PBI-00032: Adopt the ASDLC layout's rules

## Directive

Give this repository its `breadcrumb.rules`, with the layout ADR-0026
decides, and bring its breadcrumbs to that shape, so that `bcr verify`
checks every new breadcrumb against it.

**Scope:**
- In the front matter of every ADR and spec, write `follows` as
  `constrained_by`: 72 links.
- Drop the links the layout does not allow, 68 in all: every
  `implements` link from a PBI to an ADR, PBI-00022's
  `follows ADR-0008`, and ADR-0014's `changes extract`.
- Give the breadcrumbs left with too little a home: `specs/asdlc` is
  also constrained by ADR-0004, ADR-0005 and ADR-0009, and PBI-00022
  changes `asdlc`.
- Add `breadcrumb.rules` at the root, as ADR-0026 writes it.
- In `specs/asdlc/spec.md`, say that the repository declares its
  shape, list `amends` where the repository goes beyond ASDLC, and
  add a claim on `breadcrumb.rules`, so that deleting the file fails
  the pipe.
- In AGENTS.md, point the rule about new breadcrumbs at
  `breadcrumb.rules`.
- Write the new verb where a document shows this repository's links:
  README.md, `docs/bcr.md` and one Scenario of `specs/report/spec.md`.
  Generate `docs/bcr.1` again.
- In ADR-0012, write the example of a verb of two words as
  `depends_on`, as the layout writes `constrained_by`.

The data and the file are two commits: the data first, so that the
pipe passes at each.

## Dependencies
- Blocked by: PBI-00031
- Must merge before: None

## Context
Read: `specs/asdlc/spec.md`, and `specs/verify/spec.md` for
`breadcrumb.rules`.

Read: ADR-0026, for the layout; ADR-0025, for the file.

## Verification
- [ ] `go vet ./...` and `go test ./...` pass.
- [ ] `set -o pipefail; go run ./cmd/bcr extract | go run ./cmd/bcr verify | go run ./cmd/bcr audit > /dev/null`
      prints nothing and exits 0.
- [ ] `go run ./cmd/bcr extract | awk -F'\t' '$1 == "link" && ($3 == "follows" || $3 == "implements")'`
      prints nothing.
- [ ] With `breadcrumb.rules` moved away, the pipe exits 1: the claim
      on it is Refuted.
- [ ] `go test ./internal/manpage` passes.

## Refinement Protocol
If a breadcrumb cannot take the layout's shape without losing a link
that says something, stop and ask. Do not change the Decision of an
Accepted ADR: only its breadcrumb changes.
