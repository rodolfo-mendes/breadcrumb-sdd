# PBI-00006: Print where each record was written

## Directive

Add `PATH` and `LINE` at the end of the records `bcr extract` prints,
as `specs/extract/spec.md` describes, so that `bcr verify` can report
a problem where it is:

```
breadcrumb	ID	TYPE	PATH	LINE
link	ID	VERB	OBJECT	PATH	LINE
```

**Scope:**
- Give `crumb.Breadcrumb` the line of its `id`. `crumb.Link` already
  holds the line of its entry.
- Print `PATH` and `LINE` as the last two fields of each record:
  for `breadcrumb`, the line of its `id`; for `link`, the line of its
  entry.
- Update the tests of `bcr extract` for the new fields, and add a test
  for each Scenario of `specs/extract/spec.md` about the fields that
  has none.
- Describe the fields in `### extract` of `docs/bcr.md`, with the
  promise that fields may be added at the end of a record. Generate
  `docs/bcr.1` again (`go test ./internal/manpage -update`).
- Leave the reading of `.breadcrumbs` to PBI-00007, and
  `internal/frontmatter` as it is.
