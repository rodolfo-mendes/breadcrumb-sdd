# PBI-00008: Check a set of breadcrumbs in the core

## Directive

Add to `internal/crumb` the rules about a whole set of breadcrumbs,
as `specs/verify/spec.md` describes: no two have the same id, or ids
that differ only in case (ADR-0003), and every link points to an id in
the set.

**Scope:**
- Take a set of breadcrumbs, each with where it was written: an
  opaque text the caller gives, such as a path, and a line. The core
  never reads, splits or opens that text: it only repeats it in
  messages.
- Report, each at its breadcrumb's place:
  - every breadcrumb whose id is, byte for byte, another's;
  - every breadcrumb whose id equals another's under Unicode simple
    case folding (`strings.EqualFold`);
  - and name, in the message, where the others are.
- Report every link whose object is no id in the set, at the link's
  place. When the object differs only in case from an id, name that
  id in the message.
- Do not report a link to an id two breadcrumbs share: the duplicate
  is reported.
- Return the problems in order of place: the text compared as bytes,
  then the line.
- Test with sets built as values; no test reads a file or a record.
- Leave `cmd/` and the reading of a single breadcrumb as they are.
