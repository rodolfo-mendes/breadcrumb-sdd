# PBI-00026: Find what links to a breadcrumb

## Directive

Add `--object` to `bcr filter`: a `link` record matches when its
`OBJECT` field, the id the link points to, equals the flag's value. A
link is written only in the breadcrumb it belongs to, so today the
links that point to a breadcrumb are found only by reading every
other file, or with `awk` over the records.

**Scope:**
- In `cmd/bcr`, add the flag `-o ID`, `--object ID` to `bcr filter`
  and its usage line (ADR-0006). It combines with the other flags as
  they do: OR within its values, AND across flags.
- In `internal/records`, give a line read by `ReadLines` the `OBJECT`
  of a `link` record. No other kind has one.
- State the flag in `specs/filter/spec.md`, with its scenarios and a
  Definition of Done item, and add a test for each new scenario.
- Document the flag under `### filter` in `docs/bcr.md` and in its
  SYNOPSIS, and generate `docs/bcr.1` again (ADR-0008, ADR-0009).
- In AGENTS.md's Toolchain, show how to find what links to a
  breadcrumb. In README.md, show it where `bcr filter` is.
