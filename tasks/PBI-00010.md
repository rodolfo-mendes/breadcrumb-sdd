# PBI-00010: Add bcr verify

## Directive

Add the command `bcr verify`, as `specs/verify/spec.md` describes: it
reads records from standard input with the records package, checks
the set with `internal/crumb`, and prints the problems.

**Scope:**
- Add `verify` to `cmd/bcr`, with the usage line `usage: bcr verify`.
  It takes no flags and no operand; an operand is a usage error, read
  with `internal/cli` (ADR-0006).
- Read standard input to its end. On a line that is not a record,
  write `bcr: ` and the error, with the line's number in the input,
  to standard error, and exit 2.
- Print each problem as `PATH:LINE: MESSAGE` to standard error, in the
  order `internal/crumb` returns them. Print nothing to standard
  output.
- Exit 2 for an operand, input that cannot be read, or a line that is
  not a record; else 1 when there is a problem; else 0.
- Add a test for each Scenario of `specs/verify/spec.md` that has
  none.
- Document `bcr verify` in `docs/bcr.md`: a line in SYNOPSIS and a
  `### verify` subsection under COMMANDS, laid out as ADR-0008 says,
  including `set -o pipefail` for scripts. Generate `docs/bcr.1` again.
- Leave the old `bcr check` and its tests as they are.
