# PBI-00037: Let GitHub read pages.yml

## Directive

Make `.github/workflows/pages.yml` a workflow GitHub accepts. It set
`PUBLIC` in the build job's `env` from `runner.temp`, and the `runner`
context does not exist there, so GitHub refused to start a run:
`Unrecognized named-value: 'runner'`.

**Scope:**
- Set `PUBLIC` from `$RUNNER_TEMP` in a step, through `$GITHUB_ENV`,
  before the build.
- `specs/site/spec.md` already describes this state and does not
  change.

## Dependencies
- Blocked by: None
- Must merge before: None

## Context
Read: `specs/site/spec.md`.

Read: ADR-0031, for the workflow.

## Verification
- [ ] `set -o pipefail; go run ./cmd/bcr extract | go run ./cmd/bcr verify | go run ./cmd/bcr audit > /dev/null`
      prints nothing and exits 0.
- [ ] `actionlint .github/workflows/pages.yml` prints nothing; on the
      file before this change it prints the error above.
- [ ] A manual run of the workflow on `main` starts, passes its checks
      and deploys.

## Refinement Protocol
If the run fails for a reason the spec does not cover, stop and ask.
