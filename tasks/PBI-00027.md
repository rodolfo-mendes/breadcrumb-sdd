# PBI-00027: Show agents how to look breadcrumbs up

## Directive

Add to the `## Breadcrumbs` section `bcr init` writes the commands
that look breadcrumbs up with `bcr filter`: one breadcrumb by its id,
every breadcrumb of a type, what links to a breadcrumb, and a
breadcrumb's verdict, read after `bcr audit`. The section tells
agents that breadcrumbs exist, but not how to read them, so they
search the files instead.

**Scope:**
- In `cmd/bcr`, add the four commands to the agents section, as
  commands, with no other explanation.
- State them in `specs/init/spec.md`, with a scenario, a Definition of
  Done item, and the Constraint that a section written by an earlier
  `bcr` keeps its words. Add a test that runs each command the
  section shows.
- Say it under `### init` in `docs/bcr.md`, and generate `docs/bcr.1`
  again (ADR-0008, ADR-0009).

## Dependencies
- Blocked by: PBI-00026
- Must merge before: None

## Context
Read: `specs/init/spec.md`, `specs/filter/spec.md`.

## Verification
- [ ] `go vet ./...` and `go test ./...` pass, with a test for each
      Scenario of `specs/init/spec.md`.
- [ ] `set -o pipefail; go run ./cmd/bcr extract | go run ./cmd/bcr verify | go run ./cmd/bcr audit > /dev/null`
      prints nothing and exits 0.
- [ ] In a new directory, `bcr init` writes an `AGENTS.md` whose
      `## Breadcrumbs` section ends with the four commands.
- [ ] `go test ./internal/manpage` passes.

## Refinement Protocol
If a command needs a flag `bcr filter` does not have, stop and ask.
