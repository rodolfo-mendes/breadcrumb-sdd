# PBI-00036: Build the site and publish it to GitHub Pages

## Directive

Build the site `specs/site/spec.md` describes, and the workflow that
publishes it.

**Scope:**
- Add `site/`: `hugo.toml`, the landing page `content/_index.md`
  with the hero and the six sections, the layouts with no theme, one
  stylesheet, and the GitHub mark as an SVG.
- Add `.github/workflows/pages.yml`: on a tag `v*` and on
  `workflow_dispatch`, install the pinned Hugo and check its checksum,
  copy `docs/bcr.md`, build, run the spec's Regression Guardrails,
  upload and deploy.
- In `specs/site/spec.md`, replace `HUGO_VERSION: X.Y.Z` with the
  release pinned.
- Ignore `site/content/docs/_index.md` and Hugo's local output in
  `.gitignore`.
- Outside the spec, in the same change: `site/` in `AGENTS.md`'s
  Context Map, and how to preview the site in its Toolchain.
- Settings, changed by a person or with their approval: the Pages
  source becomes GitHub Actions, and the `github-pages` environment
  allows `main` and tags `v*`.

## Dependencies
- Blocked by: None
- Must merge before: None

## Context
Read: `specs/site/spec.md`.

Read: ADR-0030, for the generator; ADR-0031, for where and when the
site is published; ADR-0008, for `docs/bcr.md`. `README.md`,
`VISION.md` and `docs/bcr.md` are the sources of the landing page's
text.

## Verification
- [ ] `set -o pipefail; go run ./cmd/bcr extract | go run ./cmd/bcr verify | go run ./cmd/bcr audit > /dev/null`
      prints nothing and exits 0.
- [ ] With the pinned Hugo, `hugo --source site --destination "$PUBLIC" --panicOnWarning`
      exits 0, and each Regression Guardrail of the spec holds on
      `PUBLIC`.
- [ ] Renaming an id in `site/content/_index.md` makes the menu check
      print it; a layout that writes `href="/docs/"` makes the
      root-relative check print it.
- [ ] At 360px wide, the menu opens and closes with scripts disabled.
- [ ] Each sentence of the landing page is found in `README.md`,
      `VISION.md` or `docs/bcr.md`.
- [ ] After the settings change, the two `gh api` commands of the spec
      print `workflow`, and `main` and `v*`.

## Refinement Protocol
If the pinned Hugo cannot do what the spec asks without a script, a
root-relative link or a third file in `site/content/`, stop and ask.
If the landing page needs a statement its three sources do not make,
stop and ask.
