# PBI-00022: Describe the new model in the repository's documents

## Directive

Bring README.md, CONTRIBUTING.md, ARCHITECTURE.md and `docs/bcr.md`
up to date with the model `bcr` carries out since PBI-00021, so that
no document a reader starts from describes the old one (ADR-0024).

**Scope:**
- Rewrite README.md for the new model: a breadcrumb in a document's
  front matter, its links and claims, the four commands of the pipe,
  and how to set up `.breadcrumbs` and run them. Say nothing about the
  old model: no one outside this repository uses it.
- In CONTRIBUTING.md, build and check with the pipe in place of
  `bcr audit-report`, say that each artifact carries a breadcrumb
  (ADR-0002), call `docs/bcr.md` the user documentation, and take the
  commit example from a real commit of the new model. Drop TD-0012,
  TD-0014, TD-0016 and TK-0002: the license and the commit format are
  written where they apply (ADR-0024).
- Rewrite ARCHITECTURE.md for the four-stage pipe (Backlog item 139):
  `bcr audit` and `bcr report` in the layers, the pipeline and the
  command families; `internal/target` and `internal/page` in the
  table of packages; ADR-0016, ADR-0018 and ADR-0020 to ADR-0023
  where they apply; claims out of the Deferred table, and the
  deferrals of slices 2b to 2d in it; the section on the old model
  removed; What comes next from phase 3's plan. Link every decision,
  as the page already does, and decide nothing in it.
- In `docs/bcr.md`, call the document the user documentation, as
  ADR-0008 does, in place of the contract; say that no command takes
  a flag yet, and use `--output` in place of the old `--html` as the
  example of a long flag; and say under EXIT STATUS that `bcr report`
  exits only with 0 or 2. Generate `docs/bcr.1` again.
- Leave the ADRs, the other PBIs, the specs and AGENTS.md as they
  are.
- Leave the name of the method as each document writes it today:
  "Breadcrumb SDD" in README.md and CONTRIBUTING.md, "Breadcrumb" in
  ARCHITECTURE.md and `docs/bcr.md`. Which name stays is not decided
  here.
