# PBI-00017: Read claims, problems and targets for bcr audit

## Directive

Give `bcr audit` what it reads, as `specs/audit/spec.md` describes:
the breadcrumbs, the claims and the problems of its input, and the
files the claims are about (ADR-0021, ADR-0023). Put the rule that
joins them in the core (ADR-0022).

**Scope:**
- In `internal/crumb`, let a set hold claims and problems, each with
  its place. Give the verdict of each claim and of each breadcrumb of
  a set, from what was found at each target: a claim and a problem
  belong to the breadcrumb written at the same path.
- In `internal/records`, add a reader for `bcr audit`: `breadcrumb`,
  `claim` and `problem` records, with links and unknown kinds skipped.
  A `claim` record whose target, kind or argument the core refuses is
  not a record.
- Leave the reader `bcr verify` uses as it is: it still skips `claim`
  and `problem` records without checking them.
- Add `internal/target`, which reads a target from the current
  directory: a regular file with its content; not a file when it does
  not exist or is anything else, a symbolic link included, which is
  not followed; an error when a regular file cannot be read.
- Name `internal/target` in `AGENTS.md`'s Context Map.
- Do not add the command: that is PBI-00018.

add the rule to the spec in the same commit. If it needs a change to
the fields of a record, or to what counts as a file, stop and ask.
