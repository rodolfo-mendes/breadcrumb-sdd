# PBI-00041: Serve the site at breadcrumb-sdd.org

## Directive

Move the site's address to `https://breadcrumb-sdd.org/`, as
ADR-0033 decides, in the repository and in the settings around it.

**Scope:**
- `docs/adrs/ADR-0033-the-site-is-served-at-breadcrumb-sdd-org.md`,
  which amends ADR-0031. A maintainer sets its Status to `Accepted`.
- In `site/hugo.toml`, `baseURL`.
- In `.github/workflows/pages.yml`, the address the Check step uses
  for the sitemap and robots.txt, and the one the external-link check
  allows.
- In `specs/site/spec.md`: the link to ADR-0033, the claim on
  `baseURL`, the address in its Context and in two guardrails, an
  item of the Definition of Done, and a guardrail for the domain's
  settings.
- In `README.md`, the links to the site and its documentation.
- Leave the ADRs and PBIs that name the old address as they are:
  they are history.
- Outside the repository, in this order (ADR-0033):
  1. Verify `breadcrumb-sdd.org` in the account's settings (Settings →
     Pages → Add a domain), with the TXT record GitHub shows, and keep
     the record.
  2. Set the custom domain in the repository's Pages settings.
  3. At the registrar, remove any default or parking record and any
     wildcard, then add the four `A` and four `AAAA` records GitHub
     publishes for an apex domain, and a `CNAME` from `www` to
     `rodolfo-mendes.github.io`. Turn on auto-renew.
  4. Once the certificate is issued, turn on "Enforce HTTPS".
  5. Merge, then run the Pages workflow by hand from `main`.
  6. Add a Domain property for `breadcrumb-sdd.org` to Google Search
     Console, verified by DNS.

## Dependencies
- Blocked by: None
- Must merge before: None

## Context
Read: ADR-0033, and ADR-0031, which it amends.

Read: `specs/site/spec.md`, its Regression Guardrails.

## Verification
- [ ] `set -o pipefail; go run ./cmd/bcr extract | go run ./cmd/bcr verify | go run ./cmd/bcr audit > /dev/null`
      prints nothing and exits 0.
- [ ] With the pinned Hugo, the build and each Regression Guardrail
      of the spec pass on `PUBLIC`.
- [ ] `grep -rn 'rodolfo-mendes.github.io' --exclude-dir=.git . | grep -vE '^\./(docs/adrs|tasks)/'`
      prints nothing.
- [ ] After the deploy, the guardrail on the address passes, and
      `curl -sI https://www.breadcrumb-sdd.org/` redirects to
      `https://breadcrumb-sdd.org/`.
- [ ] `curl -sI https://rodolfo-mendes.github.io/breadcrumb-sdd/` is
      run once, and what it answers is written in the merge's pull
      request: a redirect to the new address, or not.

## Refinement Protocol
If GitHub will not issue the certificate, or "Enforce HTTPS" stays
unavailable after 24 hours, stop and ask before merging: the site
must not be served over plain HTTP at its new address.
