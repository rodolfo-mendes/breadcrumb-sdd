# PBI-00003: Read a breadcrumb from a file's front matter

## Directive

Add the front matter reader of `specs/extract/spec.md`: given the
text of a file, it finds the front matter, checks the rules of the
format, and hands the core (`internal/crumb`) the properties under the
`breadcrumb` key, each value as the text written, with its line
(ADR-0013).

**Scope:**
- Add `go.yaml.in/yaml/v3` at v3.0.5 to `go.mod`, as ADR-0010 decides.
- Add the package `internal/frontmatter`. Given a file's text, it
  returns one of: no breadcrumb; the line of the `breadcrumb` key and
  its properties, as `crumb.Property` values; or the problems of the
  format, as `crumb.Problem` values, with the lines of the file.
- Split the front matter as the spec's Architecture says. A line may
  end in `\n` or `\r\n`, and a byte order mark before the first line
  is skipped.
- Parse the front matter into a `yaml.Node` tree, never into Go
  values (ADR-0010), and turn the tree into the core's types:
  - an empty value is `NoValue`; any other plain value is
    `TextValue`, with its text as written, so `0001`, `true`, `null`
    and `~` stay text;
  - a block list, or `[]`, is `ListValue`, with an `Entry` for each
    item.
- Report as problems of the format, each at its line:
  - front matter that does not close, at line 1;
  - front matter that is not YAML, at the first line it cannot be
    read up to, since yaml.v3 does not give the line of every error,
    nor count it the same way for each;
  - a second `breadcrumb` key, or a property written twice under it;
  - a `breadcrumb` key whose value is text or a list;
  - under `breadcrumb`, anything outside ADR-0002's part of YAML: an
    anchor, an alias, a tag, a quoted value, a value over several
    lines, a flow collection other than `[]`, a map as a value, or a
    list inside a list.
- A `breadcrumb` key with no value hands the core no properties, so
  the core reports what is missing.
- Front matter that is empty, or is not a map, or has no `breadcrumb`
  key, has no breadcrumb. Keys outside `breadcrumb` are not checked
  (ADR-0002). Comments are allowed.
- Add the rules above that `specs/extract/spec.md` does not state, and
  a Scenario for front matter that is not YAML.
- Add `internal/frontmatter` to the spec's Architecture and to the
  Context Map of `AGENTS.md`.
- Leave `cmd/`, `internal/crumb` and `docs/bcr.md` as they are.
