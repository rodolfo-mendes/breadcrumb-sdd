# PBI-00001: Adopt ASDLC to develop Breadcrumb

## Directive

Set up this repository to be developed with ASDLC, as ADR-0001
decides and `specs/asdlc/spec.md` describes.

**Scope:**
- Add `docs/adrs/ADR-0001-adopt-asdlc.md`, with its status Accepted.
- Add `specs/asdlc/spec.md`.
- Add this PBI as `tasks/PBI-00001.md`.
- Rewrite `AGENTS.md` to follow ASDLC's AGENTS.md Specification.
- Rewrite the parts of `CONTRIBUTING.md` that say how a change is
  made, so they follow `specs/asdlc/spec.md`. Keep its sections on
  building and testing, commit messages and the license.
- Leave `breadcrumbs/`, `docs/breadcrumb-sdd.md`, `cmd/` and
  `internal/` as they are.

## Dependencies
- Blocked by: None
- Must merge before: None

## Context
Read: `specs/asdlc/spec.md`
- Architecture, for where each file goes
- Constraints, for where this repository goes beyond ASDLC

## Verification
- [ ] Each item of the Definition of Done in `specs/asdlc/spec.md`
      holds.
- [ ] Each claim under the spec's Regression Guardrails holds,
      checked by hand.
- [ ] `CONTRIBUTING.md` points to `specs/asdlc/spec.md` for how a
      change is made.

## Refinement Protocol
If the change needs a rule the spec does not state, add the rule to
the spec in the same commit. If it needs a change to ADR-0001's
decision, stop and ask.
