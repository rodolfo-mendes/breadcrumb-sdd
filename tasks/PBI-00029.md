# PBI-00029: Read breadcrumb.rules

## Directive

Add the reader of `breadcrumb.rules`: a package that turns the text
of the file into the rules of the core, or into the problems of the
lines its format does not allow (ADR-0025). It reads no file itself,
and `bcr verify` does not use it yet: the command follows in
PBI-00031.

**Scope:**
- Add `internal/rules`, with the name of the file and `Parse`, shaped
  like `internal/fileset`'s: text in, the core's rules or every
  problem out, each with its line.
- A line is `type`, `link` or `claims`, with 2, 4 and 2 fields
  separated by one tab. A blank line, and a line that starts with
  `#`, are ignored, as are a byte order mark and `\r` before `\n`.
- A problem is a kind it does not know, the wrong number of fields,
  an empty field, or white space in a field, with the messages
  `specs/verify/spec.md` gives. A line typed with spaces is told to
  use a tab.
- What the rules say as a whole stays the core's: a type no line
  declares, and a line written twice, are not looked for here.

the spec in the same commit. If it needs a decision ADR-0025 does not
take, stop and ask.
