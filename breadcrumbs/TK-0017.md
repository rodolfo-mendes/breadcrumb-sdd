`go run ./cmd/specsite` builds the site of the specification from the
`v` tags: a page for the latest tag of each version, `spec/latest/`,
and a list of versions at the root. Its links lead to the files on
GitHub at the page's tag. `internal/specsite` turns the specification
into HTML, and a test fails when the specification uses Markdown it
cannot read. `.github/workflows/pages.yml` deploys the site after each
successful release.

The specification's table of types became a list, and its bold terms
plain text, to keep to the part of Markdown TD-0022 allows; its
version stays 0.2.0 (TD-0030).
