# RQ-0024: bcr verdict prints the verdict of each breadcrumb

Parent: [IN-0010](IN-0010.md)

`bcr verdict` prints, on standard output, one line for each
breadcrumb: its id and its verdict, separated by a tab, such as
`TK-0001`, a tab, and `Confirmed`. With no operands, it prints every breadcrumb, in
order of path.

> Add a `bcr verdict` command that prints the verdict of each
> breadcrumb, one per line
