# IN-0011: List the breadcrumbs and their links

Parent: [IN-0005](IN-0005.md)

Add a `bcr list` command that prints each breadcrumb with its type and
title, one per line, and a `bcr links` command that prints each link
from a breadcrumb to its parent, one per line.

Motivation:

- With the verdicts, they let a pipe follow the chain from a Refuted
  Task up to what it breaks.
