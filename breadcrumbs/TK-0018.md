`bcr init` sets up Breadcrumb SDD in a repository: `TD-0001` to adopt
the specification, a `## Breadcrumb SDD` section in `AGENTS.md` or,
with `-a`, `CLAUDE.md`, and a GitHub Actions workflow that runs
`bcr check` and `bcr verdict` with the same release of `bcr`. It skips
each piece that is there, and writes nothing when it finds it cannot.
The release workflow stamps each binary with its version, which
`bcr init` needs. The contract and the README document it.
