# RQ-0044: bcr init sets up a check on each change

Parent: [IN-0017](IN-0017.md)

`bcr init` writes `.github/workflows/breadcrumbs.yml`, a GitHub
Actions workflow that runs on each push and each pull request. It
installs the release of `bcr` that ran `bcr init`, then runs
`bcr check` and `bcr verdict`, and fails when either exits other
than 0.

> It also sets up a check, run on each change, that fails when a
> breadcrumb has a problem or is Refuted.
