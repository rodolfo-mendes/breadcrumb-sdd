# TD-0010: Use only the Go standard library

## Decision

`bcr` depends on nothing outside the Go standard library, until a
need arises that the standard library cannot meet.

## Why

Every dependency is code this repository does not control and must
still trust. The standard library covers what `bcr` needs today:
reading files, parsing arguments, and writing HTML.

## What it beat

- A command-line framework such as Cobra: helpful with many commands,
  but `bcr` has one.
- A YAML parser: no breadcrumb has front matter.
