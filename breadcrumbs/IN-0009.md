# IN-0009: Check the breadcrumbs' syntax

Parent: [IN-0005](IN-0005.md)

Add a `bcr check` command that checks the syntax of the breadcrumbs
and prints each problem it finds, one per line, with the file and
line where it is. It exits with a failure when any problem is found.

Motivation:

- The toolkit's scope grows to cover syntax checks.
- Today a problem shows only inside the HTML report, which a script or
  an agent cannot read.
