# TD-0012: The contains claim

Parent: [IN-0004](IN-0004.md)

## Decision

A contains claim is written:

```markdown
- `cmd/bcr/main.go` contains `func run(`
```

The first code span is a path, relative to the repository root, using
`/` and with no `.` or `..` segments. The second is the text. Neither
holds a backtick.

The claim holds when a file exists at the path and its bytes contain
the text's UTF-8 bytes, compared exactly. The text holds no line
break, so it matches within one line.

It is the only kind of claim.

## Why

It is the smallest claim that ties a Task to code, and a reader can
check it with a text search.

## What it beat

- A SHA-256 hash of a file: exact, but no Task needs one yet, and it
  cannot be checked by eye.
- Regular expressions: more expressive, and harder to check by hand.
