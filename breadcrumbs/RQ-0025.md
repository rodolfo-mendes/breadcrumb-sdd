# RQ-0025: bcr verdict of the breadcrumbs it is given

Parent: [IN-0010](IN-0010.md)

`bcr verdict` given operands prints only the breadcrumbs they name, in
the order given. An operand is an id, such as `TK-0001`, or a path
relative to the repository root, such as `breadcrumbs/TK-0001.md`, so
that a shell pattern such as `breadcrumbs/TK-*.md` works. An operand
`-` reads them from standard input (RQ-0012).

An operand that names no breadcrumb is an error, written to standard
error; the other breadcrumbs are still printed, and `bcr verdict`
exits with 2.

> or only of the breadcrumbs it is given
