# TD-0011: Tasks and their claims

Parent: [IN-0004](IN-0004.md)

## Decision

A Task records one change as claims about the files the change left in
the repository. Each lives in `breadcrumbs/` in a file named
`TK-NNNN.md`, where `NNNN` is a four-digit number.

Its claims are the list items under a `## Claims` heading, one claim
per item, up to the next heading. Every list item there must be a
claim; one that is not cannot be read, and refutes the Task.

A Task has no status: a committed Task is audited.

## Why

A list in the body reads well in any Markdown viewer, can be checked
by eye, and needs no parser beyond the standard library (TD-0010).

## What it beat

- Claims in YAML front matter: it would bring a YAML parser, and
  nothing else in `breadcrumbs/` has front matter.
- A `.task.md` suffix: every other breadcrumb is named by its prefix.
- A status lifecycle from proposed to implemented: no Task needs one
  yet. A person approves a Task by committing it, as with the other
  breadcrumbs.
