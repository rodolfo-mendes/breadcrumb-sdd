# RQ-0039: Links lead to the breadcrumbs at the release

Parent: [IN-0016](IN-0016.md)

On a published page, a link that is relative in
`docs/breadcrumb-sdd.md`, such as `../breadcrumbs/TD-0005.md` or
`bcr.md`, leads to that file on GitHub at the tag the page was
published from, such as
`https://github.com/rodolfo-mendes/breadcrumb-sdd/blob/v0.5.0/breadcrumbs/TD-0005.md`.
A link to a web address, or to a section of the same page, is kept as
it is.

> The specification's links to the breadcrumbs of this repository
> [...] must still lead to those breadcrumbs on the published page, as
> they were at the release that published it.
