# TK-0008: Choose where the audit report is written

Parent: [RQ-0017](RQ-0017.md)
Parent: [RQ-0018](RQ-0018.md)

`bcr audit-report` takes `-o FILE` or `--output FILE` to write the
report to a file of its choosing, and `-o -` to write it to standard
output. Without `-o`, it writes `audit-report.html` as before. The
contract documents the flag.

The usage line changed, so TK-0001's claim on it was updated in place;
so was TK-0006's claim on the flags `audit-report` declares.
