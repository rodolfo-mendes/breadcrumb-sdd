# RQ-0049: A report that finds something wrong is still published

Parent: [IN-0018](IN-0018.md)

The report is published whatever it finds: a Refuted breadcrumb, or
a problem, does not stop the site from being built. The site's build
fails only when the report cannot be written.

> The report shows, at each release, whether this repository's own
> breadcrumbs hold.
