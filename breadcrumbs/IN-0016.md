# IN-0016: Publish the specification on GitHub Pages

Parent: [IN-0013](IN-0013.md)

Deploy the specification as a web page on GitHub Pages, with a stable
URL for each version of the specification, and one for the latest.

The specification's links to the breadcrumbs of this repository, such
as `../breadcrumbs/TD-0005.md`, must still lead to those breadcrumbs
on the published page, as they were at the release that published it.

Motivation:

- A reader can find and read the specification in a browser, without
  a clone of this repository or a download of `bcr`.
- A repository that adopts the method can link to the version its
  breadcrumbs follow, such as from its `AGENTS.md`, and the link keeps
  pointing to the same rules.
- A relative link that works in this repository leads nowhere on
  another site.
