# RQ-0033: bcr new writes nothing it cannot write right

Parent: [IN-0012](IN-0012.md)

`bcr new` takes its parents as `bcr verdict` takes breadcrumbs: ids,
paths, or `-` for standard input (TD-0026); with none, the breadcrumb
has no parent. It writes nothing, and exits with 2, when the type is
not one of the four, the title is empty or holds a line break, a
parent names no breadcrumb, or the next number would pass `9999`. It
never replaces a file.

> Numbering and the `Parent:` lines are easy to get wrong by hand.
