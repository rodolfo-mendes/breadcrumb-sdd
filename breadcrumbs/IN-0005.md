# IN-0005: Toolkit interface and specification

The `bcr` toolkit will follow its own specification. This new document will
specify the interface of the `bcr` toolkit: commands, inputs and outputs.

The `bcr` commands and actions are to be designed.

## Toolkit as a deterministic layer
The toolkit's scope grows to cover syntax checks, verdicts, and an interface
for authoring breadcrumbs, with its interface and contract documented for both
users and agents.

## Contract covers the interface only
The contract defines commands, flags, exit codes, and output format, and it
points to the breadcrumb that holds each rule instead of restating the rule.

## POSIX and Text Streams
These contracts must be compatible with POSIX and process text streams, so they
can be chained with Unix-like pipes (|).
