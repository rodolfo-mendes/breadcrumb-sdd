# RQ-0019: The audit report's default file

Parent: [IN-0008](IN-0008.md)

Without `-o`, `bcr audit-report --html` writes the report to
`audit-report.html` in the repository root, the directory it is run
from.

> Without `-o`, the report is still written to `audit-report.html` in
> the repository root, as in IN-0001.
