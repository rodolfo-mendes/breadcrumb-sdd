# RQ-0017: Write the audit report to a chosen file

Parent: [IN-0008](IN-0008.md)

`bcr audit-report --html -o FILE`, or `--output FILE`, writes the
report to `FILE`, replacing any file there. A relative `FILE` is taken
from the current directory. Standard output gets one line, the
absolute path of the report.

> Add a `-o` option to `bcr audit-report`, to choose where the report
> is written.
