# TD-0026: Commands name breadcrumbs the same way

Parent: [IN-0011](IN-0011.md)

## Decision

Every `bcr` command that takes breadcrumbs as operands takes them the
same way, as RQ-0025 defines for `bcr verdict`: an id, a path relative
to the repository root, or `-` for standard input. With no operands,
it takes every breadcrumb. An operand that names no breadcrumb is an
error on standard error, the others are still taken, and the command
exits with 2.

In `cmd/bcr`, one function turns operands into breadcrumbs, and every
such command uses it.

## Why

The output of each command starts with an id, so any of them can feed
any other through a pipe only if all of them read ids the same way.

## What it beat

- Each command reading its operands its own way: `bcr verdict` and
  `bcr list` would soon disagree on what `-` or a path means.
