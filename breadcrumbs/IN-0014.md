# IN-0014: Ship the specification in each release

Parent: [IN-0013](IN-0013.md)

Deploy the specification by packing `docs/breadcrumb-sdd.md` into each
release archive of `bcr`, beside the man page, `LICENSE` and
`README.md`.

Motivation:

- A repository that adopts the method gets the specification with the
  tool it runs, and keeps it for the version it adopted.
- It is the cheapest way to deploy the specification: the release
  workflow already packs files beside the binary.
