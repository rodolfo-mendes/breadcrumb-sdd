# RQ-0038: The latest version and the list of versions

Parent: [IN-0016](IN-0016.md)

`spec/latest/` shows the page of the highest version of the
specification. The site's root lists every version, highest first,
each with a link to its page and to the tag it was published from,
and links to `spec/latest/`.

> with a stable URL for each version of the specification, and one for
> the latest.
