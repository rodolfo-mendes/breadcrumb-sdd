# IN-0008: Choose where the audit report is written

Parent: [IN-0005](IN-0005.md)

Add a `-o` option to `bcr audit-report`, to choose where the report is
written. `-o -` writes it to standard output, so the report can go
down a pipe. Without `-o`, the report is still written to
`audit-report.html` in the repository root, as in IN-0001.
