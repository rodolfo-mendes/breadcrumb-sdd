# IN-0006: The bcr contract

Parent: [IN-0005](IN-0005.md)

Write a document that specifies the interface of the `bcr` toolkit:
its commands, flags, inputs, outputs, exit codes and output formats.
Document it for both users and agents, both as a Markdown document
and as a man page.

The contract covers the interface only. It points to the breadcrumb
that holds each rule instead of restating the rule.

Motivation:

- The toolkit follows its own specification, and its scope grows to
  cover syntax checks, verdicts, and an interface for authoring
  breadcrumbs.
- A rule stated in two places drifts apart.
