# IN-0015: Print the specification with bcr spec

Parent: [IN-0013](IN-0013.md)

Deploy the specification inside `bcr`: add a `bcr spec` command that
prints the specification the binary carries out, as Markdown, on
standard output.

The specification has its own version, changed only when a rule of the
method changes. Each `bcr` release says which version of the
specification it carries out.

Motivation:

- A user or an agent can read the specification offline, with nothing
  installed but `bcr`, and it is always the one that binary audits by.
- A change to the tool alone does not look like a change to the
  method.
