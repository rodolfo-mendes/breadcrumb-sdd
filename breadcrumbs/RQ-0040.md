# RQ-0040: A page stands on its own

Parent: [IN-0016](IN-0016.md)

Each page is one HTML file, with no script and nothing loaded from
another site. It shows the version of the specification and the tag
it was published from, and links to the site's root. Each heading
has an `id` made from its text, such as `verdicts`, so that a link can
point to a section.

> A repository that adopts the method can link to the version its
> breadcrumbs follow
