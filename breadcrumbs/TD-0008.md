# TD-0008: Write bcr in Go

Parent: [IN-0003](IN-0003.md)

## Decision

`bcr` and the model it runs are written in Go.

## Why

IN-0003 gives the motivation.

## What it beat

- Python: quick to write and readable, but it needs an interpreter,
  which many machines, Windows ones above all, do not have.
- Rust: one static binary too, but slower to write, and harder to read
  for people and agents.
- TypeScript on Node: strong at HTML and graphs, but it needs a
  runtime.
- Bash: hard to read and to test as a model grows, and it does not run
  on Windows without extra tools.
