# RQ-0001: An audit report command

Parent: [IN-0001](IN-0001.md)

The toolkit has a command, `bcr audit-report --html`, that a developer
runs on their own machine from the root of a repository. It audits the
repository's breadcrumbs and writes the result as a report in HTML.

> $ bcr audit-report --html
>
> This command, which is part of the toolkit, runs an automated audit
> across the breadcrumbs and generates a report in HTML format.
