`go run ./cmd/specsite` now also exports the latest `v` tag with
`git archive` and runs that tag's own `bcr audit-report --html` in it,
accepting an exit status of 1. The site publishes the report at
`report/audit-report.html`, shown in a sandboxed frame on
`report/index.html`, and the root and the README link to it.
