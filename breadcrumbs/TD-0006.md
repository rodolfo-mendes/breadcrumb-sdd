# TD-0006: Agents draft Intakes and Requirements, a person approves

## Decision

Agents may draft Intakes and Requirements. A person approves each
one before it is committed.

## Why

Intakes and Requirements state what the people behind this
repository want. An agent can word that intent, but only they can
confirm it is theirs.

## What it beat

- Agents writing them with no approval, as they write Technical
  Decisions (TD-0002): a wrong Technical Decision shows against the
  code; a wrong Requirement shows only against what someone meant.
- Only people writing them: slower, and drafting is where an agent
  helps most.
