# TD-0022: The contract is docs/bcr.md, laid out as a man page

Parent: [IN-0006](IN-0006.md)

## Decision

The contract of `bcr` is written in `docs/bcr.md`. It has the
sections of a man page: NAME, SYNOPSIS, DESCRIPTION, COMMANDS, EXIT
STATUS and SEE ALSO. Each command has its own subsection under
COMMANDS, giving its synopsis, flags, operands, standard input,
standard output and exit status.

It uses a small part of Markdown: headings, paragraphs, lists, code
spans, fenced code blocks and links. It has no tables and no HTML.

## Why

Laid out as a man page, the Markdown document can become one without
being rewritten, and a reader who knows man pages finds each part
where they expect it.

A small part of Markdown is what a man page can show.

## What it beat

- The contract in `README.md`: the README describes the method to
  newcomers; the contract is reference.
- Free layout: every command would be documented differently, and
  the man page would need its own text.
