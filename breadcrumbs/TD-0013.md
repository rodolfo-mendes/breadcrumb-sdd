# TD-0013: Where a breadcrumb sits and how it starts

## Decision

A breadcrumb sits directly in `breadcrumbs/`. A file named like a
breadcrumb in a subdirectory, or with a lower-case prefix, is not a
breadcrumb.

A breadcrumb's first line is its title, starting with `# `. A
breadcrumb that starts otherwise has a problem, shown in the report.

## Why

TD-0001, TD-0003, TD-0004 and TD-0011 name the directory and the file
but left both cases open. `bcr` had to answer them, so the answers are
recorded here rather than only in its code.

## What it beat

- Breadcrumbs at any depth under `breadcrumbs/`: subdirectories would
  carry no meaning, and two files could share an id.
- Taking the title from the first heading anywhere in the file: a
  breadcrumb could then start with text that is not its title.
