`bcr spec` prints the specification embedded in the binary by the
package `docs`, and reads no file. The specification's third line is
its version, 0.2.0, and a test keeps it in that form. Each release
archive carries the specification. The contract documents `bcr spec`
and points to the specification, and the README no longer says there
is none.

- `cmd/bcr/main.go` contains `if _, err := io.WriteString(stdout, docs.Spec); err != nil {`
- `cmd/bcr/main_test.go` contains `func TestSpecPrintsTheSpecificationOutsideARepository(t *testing.T) {`
