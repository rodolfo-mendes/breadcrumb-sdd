# IN-0003: Build bcr in Go

Build `bcr`, the toolkit command, in Go. A developer should be able to
run it on their own machine, in a repository of any stack and on any
operating system, with nothing installed but `bcr` itself.

Motivation:

- The method should reach the widest audience. A team working in Java
  or .NET on Windows may have no Python or Node, and should not need
  one to audit its breadcrumbs.
- Go builds one static binary per operating system, with no runtime to
  install.
- The audit report should be one HTML file that opens without a
  network. Go can embed the report's template and anything it needs
  inside the binary.
- The model is the definition of the method until a specification
  exists (IN-0002). Go's types make it readable as one.
- Go is widely known and quick to read, for people and for agents.
- Shell scripts grow hard to read and to test as a model grows.
