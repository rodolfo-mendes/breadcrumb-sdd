# IN-0018: The audit report on the site

Embed the audit report HTML in a page under the GitHub Pages website.

The report is the one `bcr audit-report --html` writes (IN-0001) for
the breadcrumbs of this repository, as they are at the latest
release. The page is part of the site that publishes the
specification (IN-0016), and links to it.

Motivation:

- A reader can see the method at work on a real repository, the one
  that builds it, without a clone or `bcr`.
- An adopter sees what its own report will look like before running
  `bcr init`.
- The report shows, at each release, whether this repository's own
  breadcrumbs hold.
