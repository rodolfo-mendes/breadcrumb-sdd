# TK-0005: The release workflow

Parent: [TD-0017](TD-0017.md)

A workflow builds `bcr` for six systems on each `v` tag and attaches
the archives to the tag's release.

## Claims

- `.github/workflows/release.yml` contains `tags: ["v*"]`
- `.github/workflows/release.yml` contains `run: go test ./...`
- `.github/workflows/release.yml` contains `for target in linux/amd64 linux/arm64 darwin/amd64 darwin/arm64 windows/amd64 windows/arm64; do`
- `.github/workflows/release.yml` contains `CGO_ENABLED=0 GOOS=$os GOARCH=$arch \`
- `.github/workflows/release.yml` contains `sha256sum * > "bcr_${version}_checksums.txt"`
- `.github/workflows/release.yml` contains `gh release upload "$TAG" dist/* --clobber`
