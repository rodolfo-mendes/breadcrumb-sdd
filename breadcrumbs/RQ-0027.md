# RQ-0027: bcr list prints each breadcrumb with its type and title

Parent: [IN-0011](IN-0011.md)

`bcr list` prints, on standard output, one line for each breadcrumb:
its id, its type and its title, separated by tabs, such as `TK-0001`,
`Task` and `The walking skeleton of bcr audit-report`. The type is
spelled as the breadcrumbs spell it: `Intake`, `Requirement`,
`Technical Decision` or `Task`. With no operands, it prints every
breadcrumb, in order of path.

> Add a `bcr list` command that prints each breadcrumb with its type
> and title, one per line
