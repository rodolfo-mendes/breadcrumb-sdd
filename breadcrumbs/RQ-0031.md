# RQ-0031: bcr new creates a breadcrumb under the next free number

Parent: [IN-0012](IN-0012.md)

`bcr new TYPE TITLE [PARENT|-]...` creates a breadcrumb of the type
`TYPE`, one of `IN`, `RQ`, `TD` or `TK`, in `breadcrumbs/`. Its number
is one more than the highest number of that type, or `0001` for the
first. It prints the path of the new file, relative to the repository
root, on standard output.

> Add a `bcr new` command that creates a breadcrumb of a given type,
> with its title and parents, under the next free number, and prints
> the path of the new file.
