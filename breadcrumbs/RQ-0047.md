# RQ-0047: A page with the audit report of the latest release

Parent: [IN-0018](IN-0018.md)

The site has a page at `report/` that shows the audit report of this
repository's breadcrumbs at the latest release: the highest `v` tag,
`vMAJOR.MINOR.PATCH`. The report is the file `bcr audit-report --html`
writes for the repository as it is at that tag. The page names the
tag, with a link to it on GitHub.

Like the specification's pages (RQ-0040), the page has no script and
loads nothing from another site.

> Embed the audit report HTML in a page under the GitHub Pages
> website.
