# RQ-0042: bcr init starts the breadcrumbs

Parent: [IN-0017](IN-0017.md)

`bcr init` creates `breadcrumbs/` in the directory it is run from.
When `breadcrumbs/` holds no breadcrumb, it writes
`breadcrumbs/TD-0001.md`, a Technical Decision titled
`Adopt Breadcrumb SDD`, which records the version of the
specification adopted and links to its page on the site
(RQ-0037). `bcr check` finds no problem in it.

`bcr init` prints, on standard output, the path of each file it
creates or changes, relative to the repository root, one per line.

> add a `bcr init` command that sets up Breadcrumb SDD in the
> repository it is run from. It creates `breadcrumbs/`
