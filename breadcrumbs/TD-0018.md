# TD-0018: The bcr contract is not the specification

Parent: [IN-0005](IN-0005.md)

## Decision

The contract of `bcr` asked for by IN-0005 and IN-0006 defines the
interface of `bcr`: its commands, flags, inputs, outputs, exit codes
and output formats. It is not the specification of the method that
TD-0007 defers, and it may be written now.

Where a rule of the method governs a command, the contract names the
breadcrumb that holds the rule instead of stating it.

## Why

IN-0005 calls the contract a specification, while TD-0007 writes no
specification until another repository adopts the method. The two
ask for different things: TD-0007 defers the rules of the method,
and IN-0005 asks for the interface of a tool, which scripts and
agents need as soon as the tool has one.

## What it beat

- Revising TD-0007 to allow a specification now: it would open the
  door to the rules of the method as well.
- Waiting for another repository to adopt the method: scripts and
  agents would depend on an interface nobody has written down.
