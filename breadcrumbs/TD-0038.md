# TD-0038: The page shows the report in a frame

Parent: [IN-0018](IN-0018.md)

## Decision

`report/index.html` is a page of the site, with its header and
links, that shows `report/audit-report.html`, the report as
`bcr audit-report --html` writes it, in an `iframe` as wide as the
page. The frame is sandboxed, since the report runs no script.

## Why

The report is a whole HTML document, with its own styles for the
graph. In a frame, its styles and the site's stay apart, and the
report is published byte for byte as `bcr` writes it, so it looks
the same on the site as on a developer's machine.

## What it beat

- Copying the report's SVG into the page: the two sets of styles
  would clash, and the site would need a reader of the report's HTML.
- Only a link to the report: IN-0018 asks for it embedded in a page
  of the site.
