# RQ-0037: A page for each version of the specification

Parent: [IN-0016](IN-0016.md)

The site at `https://rodolfo-mendes.github.io/breadcrumb-sdd/` has a
page for each version of the specification, at
`spec/MAJOR.MINOR.PATCH/`, such as `spec/0.2.0/`. The page shows the
specification as it is in `docs/breadcrumb-sdd.md` at the latest `v`
tag that has that version. A tag with no `docs/breadcrumb-sdd.md` has
no page.

> Deploy the specification as a web page on GitHub Pages, with a
> stable URL for each version of the specification
