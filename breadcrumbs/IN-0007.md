# IN-0007: POSIX conventions for bcr

Parent: [IN-0005](IN-0005.md)

Every `bcr` command is compatible with POSIX and processes text
streams, so commands can be chained with Unix-like pipes (`|`):

- results go to standard output as text, and errors to standard error;
- exit codes say whether a command succeeded, found something wrong,
  or was used wrongly;
- flags follow getopt style, with short flags that can be combined,
  such as `-o`, beside long ones;
- a command that takes breadcrumbs can read them from standard input.

Motivation:

- A deterministic layer that people and agents can script with the
  tools they already have.
