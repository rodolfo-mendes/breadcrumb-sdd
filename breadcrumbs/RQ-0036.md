# RQ-0036: The specification states its version

Parent: [IN-0015](IN-0015.md)

The third line of the specification is its version, written
`Version MAJOR.MINOR.PATCH`, such as `Version 0.2.0`, with nothing
after it. `bcr spec | sed -n 3p` then prints the version of the
specification a `bcr` binary carries out.

> The specification has its own version [...] Each `bcr` release says
> which version of the specification it carries out.
