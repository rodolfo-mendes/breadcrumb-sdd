# TD-0001: Adopt Breadcrumb SDD to develop Breadcrumb SDD

## Decision

This repository adopts Breadcrumb SDD to develop Breadcrumb SDD.

## Breadcrumb SDD

Breadcrumb SDD is a method for recording why a repository changed.
Code is the source of truth for what the repository does. A breadcrumb
is a small file that records intent in a form a reader can later check
against the code. The method makes drift between intent and code
visible after the fact; it does not prevent it.

## Technical Decisions

A Technical Decision records one decision about how this repository
is built. Each lives in `breadcrumbs/` at the repository root, in a
file named `TD-NNNN.md`, where `NNNN` is a four-digit number.

This file is the first.
