# RQ-0012: Breadcrumbs from standard input

Parent: [IN-0007](IN-0007.md)

A `bcr` command that takes breadcrumbs as operands reads them from
standard input when the operand is `-`, one per line. It takes the
breadcrumb's id from the first field of each line, so the output of
one `bcr` command can feed another.

> a command that takes breadcrumbs can read them from standard input
