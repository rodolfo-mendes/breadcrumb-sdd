# TD-0005: Link a breadcrumb to its parents

## Decision

A breadcrumb names each breadcrumb it derives from on its own line,
right below its title:

```markdown
Parent: [IN-0001](IN-0001.md)
```

The link is relative to the breadcrumb's own file. A breadcrumb with
no `Parent:` line has no parent.

## Why

The links make the breadcrumbs a graph that can be followed from an
Intake to what was built from it. A Markdown link can be clicked in
any viewer and checked by eye.

## What it beat

- A list in YAML front matter: nothing else in `breadcrumbs/` has
  front matter yet, and it would bring a YAML parser with it.
- A parent listing its children: every new breadcrumb would also edit
  its parent, spreading one change over two files.
