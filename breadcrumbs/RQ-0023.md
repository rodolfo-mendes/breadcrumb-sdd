# RQ-0023: bcr check warns of files that are not breadcrumbs

Parent: [IN-0009](IN-0009.md)

`bcr check` writes a warning to standard error for each file in
`breadcrumbs/` that is not a breadcrumb (TD-0013), such as
`breadcrumbs/TD-001.md`. A warning does not change the exit status.

> checks the syntax of the breadcrumbs
