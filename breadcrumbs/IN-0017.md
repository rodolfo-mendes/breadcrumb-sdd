# IN-0017: Set up a repository with bcr init

Parent: [IN-0013](IN-0013.md)

Deploy the specification into the repositories that adopt the method:
add a `bcr init` command that sets up Breadcrumb SDD in the
repository it is run from.

It creates `breadcrumbs/`, and points the repository's agents to its
breadcrumbs and to the version of the specification this `bcr`
carries out, on the published site, from `AGENTS.md`. The user
should have the option to init `AGENTS.md` or `CLAUDE.md`;
`AGENTS.md` is the default.

It also sets up a check, run on each change, that fails when a
breadcrumb has a problem or is Refuted.

It never replaces or loses what the repository already has.

Motivation:

- Adopting the method today means reading the specification and
  setting up each of these by hand, and a step missed shows only
  later.
- Pointing agents to a version of the specification keeps them on the
  rules the repository's breadcrumbs follow, even after new versions
  are published.
- A check on each change makes drift show when it happens, not when
  someone thinks to run `bcr`.
