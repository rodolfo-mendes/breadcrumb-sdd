# TK-0010: bcr verdict

Parent: [RQ-0012](RQ-0012.md)

`bcr verdict` prints each breadcrumb's id and verdict, separated by a
tab, for every breadcrumb or for those named by ids, paths, or lines
of standard input with `-`. It exits 1 when one it prints is Refuted,
and 2 when an operand names no breadcrumb. It is the first command to
read breadcrumbs from standard input, which carries out RQ-0012.
