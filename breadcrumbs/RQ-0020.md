# RQ-0020: bcr check prints each problem with its file and line

Parent: [IN-0009](IN-0009.md)

`bcr check` prints, on standard output, one line for each problem in
the breadcrumbs: `PATH:LINE: MESSAGE`, with the path relative to the
repository root. Lines are in order of path, then of line.

A problem is a breadcrumb, or a line of one, that cannot be read as
the breadcrumbs define. A claim that can be read but does not hold is
not a problem: it is a verdict.

> Add a `bcr check` command that checks the syntax of the breadcrumbs
> and prints each problem it finds, one per line, with the file and
> line where it is.
