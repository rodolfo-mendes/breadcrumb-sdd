# RQ-0006: A Refuted breadcrumb breaks its parents

Parent: [IN-0001](IN-0001.md)

A breadcrumb is Refuted when any breadcrumb that names it as a parent
is Refuted, so a break shows along the whole chain above it.

> one can track the whole chain and where it breaks: if a given Task is
> refuted, that task does not hold the Technical Decision and in turn
> breaks a requirement.
