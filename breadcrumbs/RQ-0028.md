# RQ-0028: bcr links prints each link to a parent

Parent: [IN-0011](IN-0011.md)

`bcr links` prints, on standard output, one line for each `Parent:`
link: the id of the breadcrumb that has it, and the id of the parent,
separated by a tab, such as `TK-0001` and `RQ-0001`. A link to no
breadcrumb prints the path it points to in place of the parent's id.
With no operands, it prints every link, in order of the path of the
breadcrumb that has it, then of its `Parent:` lines.

> a `bcr links` command that prints each link from a breadcrumb to its
> parent, one per line
