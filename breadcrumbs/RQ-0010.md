# RQ-0010: Exit codes

Parent: [IN-0007](IN-0007.md)

A `bcr` command exits with:

- 0 when it succeeded and found nothing wrong;
- 1 when it ran and found something wrong in the breadcrumbs;
- 2 when it was used wrongly, or could not run.

A failure to run, such as a directory that cannot be read, exits with
2, so that it is never mistaken for something wrong in the
breadcrumbs.

> exit codes say whether a command succeeded, found something wrong,
> or was used wrongly
