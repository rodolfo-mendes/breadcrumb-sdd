# IN-0010: Print the verdicts

Parent: [IN-0005](IN-0005.md)

Add a `bcr verdict` command that prints the verdict of each
breadcrumb, one per line, or only of the breadcrumbs it is given. It
exits with a failure when any of them is Refuted.

Motivation:

- The toolkit's scope grows to cover verdicts.
- A script or an agent can then fail a build, or find what broke,
  without reading the HTML report.
