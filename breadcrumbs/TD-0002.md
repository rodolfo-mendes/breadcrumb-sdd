# TD-0002: Point agents to the breadcrumbs through AGENTS.md

## Decision

Agents working in this repository learn about its breadcrumbs from
`AGENTS.md` at the repository root. Agents may write Technical
Decisions themselves.

## Why

An agent that does not know `breadcrumbs/` exists cannot follow the
decisions recorded there. `AGENTS.md` is read by many coding agents,
so one file serves them all.

## What it beat

- `CLAUDE.md`: read by one agent only.
- Agents proposing Technical Decisions for a person to write: safer
  while decisions can only be checked by eye, but slower. Agent-written
  decisions still land in git, where anyone can read them.
