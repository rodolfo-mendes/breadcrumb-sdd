# RQ-0043: bcr init points agents to the specification

Parent: [IN-0017](IN-0017.md)

`bcr init` gives the agents file (RQ-0046) a section headed `## Breadcrumb SDD`. The section says that the repository is
developed with Breadcrumb SDD, links to the page of the version of
the specification that `bcr spec` prints, such as
`https://rodolfo-mendes.github.io/breadcrumb-sdd/spec/0.2.0/`, and
asks agents to read the breadcrumbs before changing the repository,
to record each change as the specification says, and to run
`bcr check` and `bcr verdict`.

It creates the agents file when there is none, and adds the section at its
end when it has none.

> points the repository's agents to its breadcrumbs and to the version
> of the specification this `bcr` carries out, on the published site,
> from `AGENTS.md`.
