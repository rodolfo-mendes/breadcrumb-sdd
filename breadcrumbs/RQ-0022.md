# RQ-0022: A Parent link to no breadcrumb is a problem

Parent: [IN-0009](IN-0009.md)

A `Parent:` line whose link points to no breadcrumb is a problem, on
the line of the link. `bcr check` prints it, and `bcr audit-report`
lists it with the other problems.
