`bcr check` prints each problem in the breadcrumbs as
`PATH:LINE: MESSAGE` and exits 1 when it finds one. The model gives
each problem its line, and a `Parent:` link to no breadcrumb is now a
problem, which `bcr audit-report` lists too. `bcr check` warns of each
file in `breadcrumbs/` that is not a breadcrumb.

Each command now has its own usage line, so TK-0001's claim on the
usage line was updated in place.
