# RQ-0045: bcr init keeps what the repository has

Parent: [IN-0017](IN-0017.md)

`bcr init` never replaces a file, and changes none but the agents file
(RQ-0046), and that only by adding its section at the end. A file it
would write that is already there, or an agents file that already
has a
`## Breadcrumb SDD` heading, is left as it is, with a note on
standard error.

It finds everything it cannot do before it writes anything: then it
writes nothing and exits with 2. Otherwise it exits with 0, also
when it had nothing left to do, so running it twice changes nothing
the second time. It takes no operands, and no flag but `-a` (RQ-0046).

> It never replaces or loses what the repository already has.
