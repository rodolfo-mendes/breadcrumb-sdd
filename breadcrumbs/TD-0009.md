# TD-0009: Keep the model apart from the command and the report

Parent: [TD-0007](TD-0007.md)

## Decision

The model of breadcrumbs lives in its own Go package,
`internal/breadcrumb`. The command, in `cmd/bcr`, and the HTML report,
in `internal/report`, use the model; the model uses neither.

## Why

Until a specification exists, the model is the definition of the
method (TD-0007). Kept apart, it can be read as one without reading
how a command parses flags or how a report draws boxes.

## What it beat

- One package for everything: shorter, but the definition would be
  spread through code that has nothing to do with the method.
