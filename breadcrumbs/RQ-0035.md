# RQ-0035: bcr spec prints the specification it carries out

Parent: [IN-0015](IN-0015.md)

`bcr spec` writes the specification, as Markdown, to standard output:
the bytes of `docs/breadcrumb-sdd.md` in the commit the binary was
built from, and nothing else. It reads no file, so it runs outside a
repository, and exits with 0. It takes no flags and no operands; given
any, it exits with 2 (RQ-0010).

> add a `bcr spec` command that prints the specification the binary
> carries out, as Markdown, on standard output.
