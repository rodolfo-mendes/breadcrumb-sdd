# RQ-0046: bcr init writes AGENTS.md or CLAUDE.md

Parent: [IN-0017](IN-0017.md)

`bcr init` gives its section (RQ-0043) to one file at the repository
root, the agents file: `AGENTS.md` by default, or the file named by
`-a FILE` or `--agents-file FILE`. `FILE` is `AGENTS.md` or
`CLAUDE.md`; any other value is a usage error, and nothing is
written (RQ-0045).

> the user should have the option to init AGENTS.md or CLAUDE.md;
> AGENTS.md is the default
