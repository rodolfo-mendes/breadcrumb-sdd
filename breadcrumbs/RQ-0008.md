# RQ-0008: A breadcrumb is Confirmed when all below it are

Parent: [IN-0004](IN-0004.md)

A breadcrumb that other breadcrumbs name as a parent is Confirmed when
every one of them is Confirmed. When none is Refuted but some are
Undecided, it is Undecided. A breadcrumb other than a Task that no
breadcrumb names as a parent is Undecided.

> A breadcrumb above it is Confirmed only when every breadcrumb below
> it is Confirmed.
